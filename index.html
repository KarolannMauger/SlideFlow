SlideFlow

Local-first · No backend · HTML slides

Build and present HTML decks. No PowerPoint needed.

SlideFlow is a browser-based tool for developers and creators who prefer HTML over presentation software. Write slides in HTML, drag to reorder, and present in fullscreen — no account, no backend, everything lives in your browser.

What you can do

  • 📄
    Write each slide as a plain HTML file — full design control.
  • ⤢
    Drag to reorder or drop your HTML files directly onto the deck.
  • ⛶
    Present in fullscreen with arrow key navigation and a progress bar.
  • ☁️
    Deploy to GitHub Pages and share your presentation as a URL.
  • 🤖
    Use AI-generated HTML slides as a ready-to-present deck instantly.
